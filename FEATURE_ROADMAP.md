# VFR3D Feature Roadmap

Recommended features for private pilots and student pilots.

## High Priority (Safety-Critical)

- [ ] **NOTAMs (Notices to Air Missions)** - NOTAMs by airport, along route, FDC NOTAMs, filtering by category
- [ ] **TFR (Temporary Flight Restriction) Detection** - Real-time TFR data, route conflict detection, notifications
- [ ] **Weight & Balance Calculator** - Aircraft-specific W&B profiles, CG envelope visualization, common load configs
- [ ] **Sunrise/Sunset/Civil Twilight Times** - Times for departure, destination, waypoints; arrival time warnings

## Medium Priority (Training & Convenience)

- [ ] **Consolidated Weather Briefing** - Standard briefing view combining synopsis, METARs, TAFs, hazards, NOTAMs
- [ ] **Pilot Logbook / Flight Time Tracking** - Log flights, track categories, currency calculations, certificate progress
- [ ] **Alternate Airport Recommendations** - Find alternates by range, runway length, lighting, services, weather
- [ ] **Emergency/Diversion Airport Finder** - Nearest airports by position, glide distance, runway suitability
- [ ] **Cost Estimator** - Fuel costs, rental rates, instructor time, trip cost summary

## Lower Priority (Nice to Have)

- [ ] **Personal Airport Notes** - User notes on airports, FBO preferences, fuel prices
- [ ] **Training Area Management** - Save practice area polygons, quick route generation, maneuver tracking
- [ ] **Instructor/Student Collaboration** - CFI flight plan review, pre/post flight feedback, training progress
- [ ] **Checklist Builder** - Aircraft-specific checklists, emergency procedures, completion tracking

## Suggested Starting Point

1. **NOTAMs** - Required for every flight, currently missing
2. **Weight & Balance** - Students use this every flight
3. **Sunrise/Sunset** - Simple to implement, legally required for VFR
